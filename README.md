# SaltMark · 析盐砖样台

在砖样照片上取原图测量框和真实原行。每个像素的最低 RGB 分量达到所设下限，且通道最大差不超过设定值时，记为近中性浅色。原照每个点的 RGB 保留，可检查原行浅色比例和框内全行的实际分布。

把截线放在浅痕实际起线后，可确认从起线向上连通的浅色簇：只认上下左右真正相邻、任一通道为 0 或 255 即不算的实点，候选须在起线上至少有四个连续真点且不触左右框边；多簇时按实际上爬高度和真实覆盖面积建议一簇。采用后原行覆盖可只数该簇像素，原行剖面和 CSV 标出簇内点，PNG 校样标出同一簇和真实最高点，整框普通覆盖照常查看。

使用标有合成说明的练习，或导入自己的单帧 PNG、JPEG、TIFF、BMP、WebP。设置可以保存重开，可输出真实源点 CSV、PNG 校样和包括原图的 ZIP，也可将原照送到照片准备。

`docker compose up --build` 后访问 `http://127.0.0.1:19926/`。只监听本机，命名卷保留原照、测量和准备工程。
