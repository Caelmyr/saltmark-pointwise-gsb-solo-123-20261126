# SaltMark · 析盐砖样台

在砖样照片上取原图测量框和真实原行。每个像素的最低 RGB 分量达到所设下限，且通道最大差不超过设定值时，记为近中性浅色。原照每个点的 RGB 保留，可检查原行浅色比例和框内全行的实际分布。

使用标有合成说明的练习，或导入自己的单帧 PNG、JPEG、TIFF、BMP、WebP。设置可以保存重开，可输出真实源点 CSV、PNG 校样和包括原图的 ZIP，也可将原照送到照片准备。

同一块砖擦拭前后的两张原照可以对照：为第一张选第二张砖样卡，各点几对同一固定印记的原 X，只给第二张一个统一整数位移，使第一张原 X 加位移即第二张原 X。移量与每对实标剩余偏差都不得超过所填上限；只有两侧截线共同覆盖的点算共见，任一 RGB 通道为 0 或 255 的配对标为无证、不算未变。符合最低共见点数的候选中兼顾真原点重叠与印记对位求解，可手动采用。采用后各张用原有阈值在截线上区分浅色新增、减少、未变与无证，点第一张原截面即切到第二张对应点并读出实际配对的 X/Y 与 RGB，可导出对照 CSV。

`docker compose up --build` 后访问 `http://127.0.0.1:19926/`。只监听本机，命名卷保留原照、测量和准备工程。
